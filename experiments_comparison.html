关键结论

🏆 综合最优：实验 1

mAP@0.5:0.95 最高（0.6106），Precision 最高（0.8821），训练时间最短（1h41min）

🎯 最高 Recall：实验 4

Recall=0.8436（最高），832 分辨率 + LRF=0.01 让模型检出更多目标

⚠️ 失败案例：实验 2

yolov8l（43.7M 参数）+ 958 张小数据集，明显过拟合，所有指标最差

💡 意外发现

实验 4 把 LRF 从 0.05 改回 0.01，mAP50-95 反而略降（0.6069→0.6040），但 Recall 大幅提升

📊 四次实验综合分析：

1. 实验 1（综合最优）：yolov8m + 640 + LRF=0.01。mAP@0.5:0.95 = 0.6106（最高），训练时间最短（1h41min），各指标均衡优秀。

2. 实验 2（过拟合）：yolov8l + 832 + LRF=0.05。参数量翻倍但数据不足，所有指标最差。

3. 实验 3（高分辨率）：yolov8m + 832 + LRF=0.05。mAP@0.5 最高（0.8896），但 LRF=0.05 让后期震荡。

4. 实验 4（高召回）：yolov8m + 832 + LRF=0.01。Recall 最高（0.8436），但 Precision 最低（0.8005），出现"多检测"倾向。

🔍 实验 3 vs 实验 4 对比（同 imgsz=832，仅 LRF 不同）：

· LRF 从 0.05 → 0.01：终点 lr 从 2.5e-5 → 5e-6（更小，理论上更精细收敛）

· 实际结果：mAP50-95 略降（0.6069 → 0.6040），但 Recall 提升（0.8167 → 0.8436）

· 推测：832 分辨率已经能让模型充分学习，更小的 final_lr 反而让模型过度收敛，倾向于"保守检测"（多检出，宁可错杀）
